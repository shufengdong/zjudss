## git

### Git简介

Git是目前世界上最先进的分布式版本控制系统，是用C语言开发的。Git是分布式版本控制系统，它的使用不必联网，有强大的分支管理能力。GitHub网站为开源项目免费提供Git存储，通过这个开源协作社区的克隆和分支功能，广大用户可以自由参与各种开源项目。

### 在Ubuntu Linux上安装Git

首先在终端输入`git`，检验系统是否已经安装git：

```shell
git

Command 'git' not found, but can be installed with:

sudo apt install git
```

若出现git help命令引导，则说明已经安装。若出现如上命令，则说明没有安装。

按照提示，输入`sudo apt install git`或`sudo apt-get install git`，就可以完成安装。

配置`user.name`和`user.email`，它的作用相当于给自己的机器加上一个身份证：

```shell
git config --global user.name "xxxxx"
git config --global user.email "xxxx@xxxx.com"
```

## gcc

### GCC简介

Gcc是一款功能非常强大的编译工具。

### 在Ubuntu Linux上安装Gcc

首先在终端输入`cc --version`，检验系统是否已经安装GCC，如果已经安装好 GCC，并链接到名为 cc 的默认C编译器，就会看到编译器的版本号和版权信息：：

```shell
$ cc --version
cc (GCC) 4.9.2
Copyright (C) 2014 Free Software Foundation, Inc.
This is free software; see the source for copying conditions.
There is NO warranty; not even for MERCHANTABILITY or FITNESS
FOR A PARTICULAR PURPOSE.
```

有可能已经安装好 GCC，但是并没有链接到程序名称 cc。为解决这种情况，可以试着使用 GCC 的正式名称来调用它：
```shell
$ gcc --version
```
否则，则需要自己安装GCC，使用命令`sudo apt-get update`，`sudo apt-get install gcc`



## jdk

若需要使用 ray 与 java 的交互部分，应该安装 jdk 。这里以 Ubuntu 16.04 下安装 openjdk 8 为例，在终端中键入：
```shell
sudo apt-get install -y openjdk-8-jdk
```

## bazel和camke

### 安装 bazel

ray 中的 bazel 配置使用了较旧的语法，不兼容新版本，因此需要安装 bazel 1.1.0 。
使用 ray 中提供的脚本进行安装：
```shell
ray/ci/travis/install-bazel.sh
```

### 安装 cmake

```shell
sudo apt-get install -y cmake
```
