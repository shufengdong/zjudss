# 当前会话案例整体切换

用户已确认：使用案例默认替换当前会话的上一案例；成功时创建/复用并激活模型版本，替换配套 Data/Struct，清空旧草稿。保留历史模型、运行、结果和资源引用。上一案例参数修改随案例一起退出当前可用集合。

普通上传仍使用双子事务；案例确认使用单 SQLite 事务。案例准备期间不改变当前模型与资源。案例模型整体替换，不残留旧表。历史案例资源及其 replacement 后代退出当前集合，用户普通资源不自动覆盖；冲突阻止整个切换。模型内容相同复用已有版本。

确认卡明确提示覆盖草稿与案例参数、自动激活及历史保留。案例候选按目录角色整体确认，不提供改变用途或跳过部分案例输入。确认请求继续使用稳定批次 ID、expectedDraft 和幂等操作 ID，不接收路径或 SQL。

实现选择：复用现有资源发布和版本发布的事务内函数，外层事务包住退役旧案例资源、模型草稿替换、模型版本发布和新资源发布。与仅自动改 alias、分步提交后补偿相比，可避免混合状态。
