# RSS 脚本生成

## 何时使用
用户明确要求创建或修改不属于目录门面管理研究的通用 RSS 时使用。

## 执行步骤
1. 本技能只处理用户明确要求保存的通用手工 RSS。目录门面管理的研究必须通过 `prepare_study` 配置卡和“确认并生成脚本”进入专用工作流，不得调用本技能或 `create_script` 绕过确认。
2. 按需用 `search_engine_docs` 和 `read_engine_doc_section` 读取语法与函数资料；不要根据历史脚本猜语法。
3. DataFrame 脚本只能包含变量声明。函数结果绑定本身就是输出；最后一个或多个未被后续声明消费的 DataFrame 变量会由引擎写入结果目录。函数调用后不要追加 `summary_result;`、`voltage` 等裸变量表达式。`height`、`width` 等标量只能作为中间值被后续 DataFrame 表达式消费，禁止留下未被后续节点消费的纯标量。
4. 不得用通用脚本接口生成目录门面的受管研究脚本。
5. 生成后调用 `create_script` 保存；实际运行只由用户点击脚本卡片按钮发起。

## 禁止推断
不得手写未在 catalog 中出现的函数；不得进行网络访问、服务器路径或任意文件读取。

## 验收
通用脚本保存实际 artifact、bundle/技能版本和结构化诊断；受管研究脚本由确认后的专用 author 负责。
