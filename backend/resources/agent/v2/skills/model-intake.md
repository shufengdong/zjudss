# 模型输入整理

## 何时使用
用户上传、补传、替换或移除 RSS、bundle、CSV、Excel、Parquet 时使用。

## 执行步骤
1. 读取 active/draft 和摄取状态，只按表头证据判断 DataFrame 类型。
2. 多个候选、同类型重复表或替换关系不明确时，列出候选和缺失列并询问用户。
3. 修改必须携带当前 expected draft/base 版本 ID；冲突后重新读取工作区。
4. 新文件形成新 artifact 和版本，保留旧版本用于回退和比较。

## 禁止推断
不得用文件名、工作表名或上传先后覆盖已有输入；不得接受服务器路径。

## 验收
版本清单含内容 hash、角色、规范相对路径、映射证据和诊断。
